## Alibaba Normalization Note

The successful Alibaba Actor returned some image URLs ending in `.jpg.jpg`. Direct checks showed those URLs can return 404 placeholder images. Removing the duplicate extension produced real image responses:

- `https://s.alicdn.com/@sc04/kf/Hbd6ea44415cc4512844f1c55e3c57c13H.jpg` returned `HTTP 200`, `image/jpeg`, `content-length: 164336`.
- `https://s.alicdn.com/@sc04/kf/H24b2023ec44a4ed59505c39227cb78e2A.jpg` returned `HTTP 200`, `image/jpeg`, `content-length: 124819`.

Alibaba candidates must therefore pass a normalization and `curl`/browser verification step before they are treated as usable visual assets.

- Product detail images from the logged-in page included `product-img` URLs under `s.alicdn.com/@sc01/kf/`.
- `https://s.alicdn.com/@sc01/kf/Hf08041b80c3f44b1817e5b0151275cfbl.jpg` returned `HTTP 200`, `image/jpeg`, `content-length: 322487`.
- `https://s.alicdn.com/@sc01/kf/H752bd0ac798f48f887601ff84a54fb972.jpg` returned `HTTP 200`, `image/jpeg`, `content-length: 43189`.
- The product video URL returned `HTTP 200`, `video/mp4`, `content-length: 3260498`.

Codex can use Chrome control and `pageAssets`, but that is not portable by itself. Other local agents should use one of these adapters:

- Browser adapter: use a logged-in persistent browser profile and query rendered `document.images`, background images, `video`, and `source`.
- Cookie-session adapter: run `.claude/skills/visual-material-hunt/scripts/alibaba_cookie_probe.py URL` with `python3.12`; cookies stay in memory and the script prints only page/media metadata.
- Actor fallback: use `getdataforme/alibaba-category-scraper`, then normalize and verify media URLs.

Do not print or store cookie values. Use the authenticated state only to read the rendered page or fetch page HTML for source-backed media candidates.

## Practical Conclusion

The combined workflow is usable for article visual sourcing, but the source hierarchy should be:

1. You MCP for fast discovery and thumbnail-bearing leads.
2. Exa for project/case pages that can improve authenticity beyond generic product images.
3. Tavily image search for direct image URL expansion.
4. Made-in-China and 1688 for concrete marketplace image pools.
5. Alibaba authenticated Chrome + `pageAssets` when the operator is logged in.
6. Alibaba through `getdataforme/alibaba-category-scraper` when browser login is unavailable, followed by image URL normalization and access checks.

For this article, the best next step is not immediate article editing. The next step is a lightweight relevance check over the candidate image URLs, then selecting only the visuals that improve the article's explanation, proof, or comparison moments in `image-plan.md`.

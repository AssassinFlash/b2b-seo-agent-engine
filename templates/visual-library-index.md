## Reuse Rules

1. **Check this index before searching for new assets.** If a reusable asset exists, use it.
2. **New assets must be registered here** after they are promoted in any article's visual spec.
3. **Tags must be added** so future articles can find the asset by concept.
4. **"Reusable?" flag**: set to "yes" for generic assets (product photos, diagrams); set to "no" for article-specific assets (e.g. a chart with article-specific data).
5. **Source attribution** must be recorded for every asset — where it came from, who made it, license if applicable.
